# Block-2-Project
This is a repository for my CS3090 course; its contents are a README and a LICENSE to fulfill the purpose of the assignment. This is public for the purpose of this assignment. 

This repository is used for my course assignments and workshops. As a games student, most of my tasks are completed in Unreal Engine 5, so this contains the content I create that I would usually put in an Unreal Project. It contains everything from 2D and 3D art assets to blueprints/code. This is to help me easily access my work from any computer, whether on campus or off. It also helps me maintain a backlog of changes and different branches so that I can test out different ideas in Unreal without ruining the functional version.
